# pill-count.github.io

Manage pill stock and estimate when to reorder repeat prescriptions.

Open `/index.html` in a browser or publish the repository with GitHub Pages.

The planner understands the same query parameter format as the original example:

- `datum=dd-mm-yyyy` target date
- `aantal=2_2` daily pills per medicine
- `dozen=100_100` pills per box
- `voorraad=140_45` current stock per medicine
- `buffer=14` safety buffer in days
